### 版本化 git hooks

hooks 放 `.githooks/` 并入库（不是 `.git/hooks/`，那里不入库），用 `git config core.hooksPath .githooks` 启用。

- `pre-commit`：grep 暂存区文件名，拦截 `local.properties` / `build/` / `*.apk` 等。已实测拦截生效。
- `post-commit`：后台静默 `codegraph sync`，输出追加到 `.git/codegraph-sync.log`（含时间戳与 commit id）。
  已验证：每次提交后日志确实新增一条，且不阻塞提交。

### CodeGraph

- `codegraph init -y` → 25 文件 / 604 节点 / 1177 边 / 4.5s，索引 1.86MB，后端 node:sqlite WAL。
- 增量验证：临时加一个 `IndexProbe.kt` → 26 文件 608 节点，删除后精确回退 25/604。
- **中文查询无效**：`codegraph explore "分页时如何处理行距"` 返回 "No relevant code found"。
  它按代码标识符关键词匹配，没有中文语义检索，必须写英文（`explore "pagination line spacing"` 才命中）。
  `explore` 会附带 blast radius（谁依赖、有无测试覆盖），比直接读文件省事。
